# Timediffer
A tool to get the decimal time in hours between two timepoints with a subracted pause
The tool is just for easy time registration

## Usage
```bash
$ timediff --help
Usage: Time diff tool <from> <to> [<pause>]

A simple tool to helpt get the amount of hous from a start too and end time with an added pause

Arguments:
  <from>       Startime (HHMM)
  <to>         Endtime (HHMM)
  [<pause>]    Pause in minutes

Flags:
  -h, --help    Show context-sensitive help.
  -q, --quiet    Quiet or not
```
